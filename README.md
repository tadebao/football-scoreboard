# 足球比分大屏 · Football Scoreboard

一款为业余足球赛事打造的**原生桌面比分投屏工具**。一个窗口控制，一个窗口投屏——把实时比分、比赛时间和球队信息一键投到副屏 / 投影仪，现场零依赖、即开即用。

## ✨ 功能特性

- **双窗口协作**：控制台（操作）＋ 大屏（投屏），大屏可拖到副屏全屏展示
- **精准计时**：开赛 / 暂停 / 继续；可开关「45 / 90 分钟自动暂停」提示
- **比分管理**：双方比分一键 `+1`；「比分归零」只清比分、不打断计时
- **整场重开**：停表 + 清阶段，带二次确认防误触
- **球队与赛事**：自定义队名、赛事名、球衣色、队徽 / 背景素材
- **大屏布局**：元素可拖动 / 缩放 / 多选，布局按比例存储，换分辨率不变形
- **时间安全**：检测到系统时间异常会弹出醒目提示，避免计时错乱
- **整洁界面**：高级调试功能默认隐藏，连点左上角 ⚽ 5 次解锁

## 🚀 快速开始（分发即使用）

无需安装。把 `dist/football-scoreboard/` **整个文件夹**复制到目标机器即可：

```
football-scoreboard/
├─ football-scoreboard.exe   ← 双击启动
├─ data/                     ← 运行期状态（比分、布局、素材）
└─ fonts/                    ← 显示字体
```

1. 双击 `football-scoreboard.exe` 启动（无控制台黑窗）
2. 在控制台填写两队名称、赛事名称，选好球衣色，点「开赛」开始计时
3. 将「大屏」窗口拖到投影副屏，按 `F` 进入全屏
4. 比赛中用 `+1` 更新进球；需修正比分用「比分归零」（计时继续）

## ⌨️ 大屏快捷键

| 操作 | 效果 |
|------|------|
| `F` | 全屏 / 退出全屏 |
| `Esc` | 关闭大屏窗口 |
| 单击 | 选中元素并拖动调整位置 |
| `Ctrl + 点击` | 多选元素 |
| `Ctrl + - / =` | 缩放选中元素 |
| 双击 | 复位元素到默认位置 |

## 📋 控制台按钮说明

- **开赛 / 暂停 / 继续**：控制比赛计时走停
- **比分归零**：仅清比分，计时不受影响（用于比赛中途改分）
- **整场重开**：停表 + 清比分 + 清阶段，带 3 秒二次确认（用于换场或一场结束）
- **45 / 90 自动暂停**：到半场 / 全场节点自动提示，可在比赛中临时关闭
